x86 register & flags manual

Register names, conventional roles, and the meaning of each displayed flag.

General-purpose registers

i386Full name / conventional role
EAXAccumulator — arithmetic results, function return values, and legacy syscall numbers.
EBXBase register — general-purpose; historically used as a base pointer and for syscall arguments.
ECXCount register — loop counts and shift counts; also a general-purpose register.
EDXData register — paired arithmetic data and I/O; also a general-purpose register.
ESISource index — source pointer for string operations; also general-purpose.
EDIDestination index — destination pointer for string operations; also general-purpose.
EBPBase/frame pointer — often anchors a stack frame; also general-purpose.
ESPStack pointer — points to the current top of the stack.
x86-64Full name / conventional role
RAX64-bit accumulator; low portions are EAX, AX, AH, and AL.
RBX64-bit base register; general-purpose in x86-64.
RCX64-bit count register; used by some instructions and calling conventions.
RDX64-bit data register; used by some instructions and calling conventions.
RSI / RDISource / destination index registers; also used for argument passing on common 64-bit ABIs.
RBP / RSPFrame/base pointer / stack pointer. RSP tracks the current stack top.
R8–R15Additional 64-bit general-purpose registers. Their low 32-, 16-, and 8-bit names end in d, w, and b.

Legacy role names describe common uses, not restrictions: most of these registers can be used as general-purpose registers. The byte and word aliases are the low-order portions of their parent register.

EFLAGS / RFLAGS flags

FlagBit(s)Full nameMeaning
CF0Carry FlagCarry or borrow from an unsigned arithmetic operation.
PF2Parity FlagSet when the low byte of a result has even parity.
AF4Auxiliary Carry FlagCarry between bit 3 and bit 4; used by some BCD operations.
ZF6Zero FlagSet when an operation's result is zero.
SF7Sign FlagCopies the most-significant result bit; indicates a negative signed result.
TF8Trap FlagEnables single-step trap behavior when set.
IF9Interrupt Enable FlagControls recognition of maskable interrupts when permitted.
DF10Direction FlagControls the direction used by string instructions.
OF11Overflow FlagIndicates signed arithmetic overflow.
IOPL13:12I/O Privilege LevelTwo-bit privilege level controlling certain I/O operations.
NT14Nested Task FlagControls nested task handling in legacy task switching.
RF16Resume FlagControls debug exception behavior for the following instruction.
VM17Virtual-8086 Mode FlagIndicates virtual-8086 mode when supported and active.
AC18Alignment Check FlagEnables alignment checking in applicable privilege modes.
VIF19Virtual Interrupt FlagVirtualized interrupt-enable state.
VIP20Virtual Interrupt Pending FlagIndicates a pending virtual interrupt.
ID21ID FlagCan indicate whether the CPUID instruction is supported.

Flag values are shown in binary; for IOPL, the display is the two-bit value. In x86-64 mode the panel uses the EFLAGS layout for the low 32 bits of RFLAGS and does not display upper bits 32–63.
